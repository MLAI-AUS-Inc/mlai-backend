# D2 independent source-stop advancement

A source-only wake now retains a private causal fence. The paired stop outbox
must advance before journey/proof reads, because missing old usage or stale
source may otherwise prevent the goal from reaching its article step.
The actual prepare controller now drains this purpose before journey checks.

A separate action=article-source-stop row persists one stop identity and exact
wire request per causal fence. It reuses the original goal/payment; it never
reserves a model or debits points. Each admission and pre/post-HTTP commit
reloads original owner/company/consent, unchanged old request/operation attempt
and actual original spend/refund/payer through canonical billing authority.
A 60-second nonce lease and exact prepare claim prevent concurrent calls and
allow a lost reply to retry the identical request after expiry. No site lock
is held across HTTP. Authentication and bounded private transport are reused.

The purpose returns empty capabilities and permission_mode=none. Generic
validation permanently denies both private source-fence and source-stop
actions, including after flag rollback and for cleanup/cancellation variants.
Later owner revocation cannot commit an observation or turn it into a read
or replacement grant. Ordinary setup/scan replay and sparse legacy controls
keep their existing paths.

The worker receipt is a local control acknowledgement, always quiet=false,
inventory_complete=false and effect_authority=false. The backend continues
to wait for complete reconciliation and records remote_confirmed=false. It
does not yet grant historical artifact reads or a replacement. Next work is
independent token/resource/operation inventory closure, complete accounting,
owned publication/auto-merge reconciliation, a separately admitted historical
read and durable content seal, then current-source execution under the same
original paid root. All rollout flags remain off; draft only.

Reconciliation inherits the original wall, compute, model and class limits.
The first effect-removal pass runs before evaluating those limits; an expired
goal then stops with its original budget reason instead of polling forever.

Validation: 551 combined source-stop/refresh/fence, first-article, lifecycle,
incident, facade/profile and sparse-settings checks pass without DB or network.
The generic-private-action denial regression fails on the preceding backend
revision. All 604 test modules are selected in CI. The read-only model check
reports no changes. Contract, transport and actual synthetic stop examples
are pinned to CF `bdf4bf31fda728839c2dde322c14adc219470187`; the stop
examples are generated by the actual worker control path.

The final remote checks job exposed a Phase A source-work assertion that
prohibited the new ownership lookup. Reproduced the exact test failure, then
allowed only that prepare lookup while still asserting no source-work update.
The full failing website journey/lifecycle CI lane plus the related controls,
source-stop/source-policy and facade/profile lanes now pass 1,807 checks
across 130 modules with database/network access denied. No production
authority or test mutation assertion was relaxed.
