# E5: native CMS goal ledger and private proof reader

The existing repository goal requires actual source/commit/build/merge facts.
Native CMS work now has a separate closed ledger and proof reader. Its scope
contains the actual provider/site/company/owner/generation binding and exact
private publication-policy reference. Source identity is the original CF run,
run generation and artifact-envelope digest. It introduces no Git source SHA.

The nine familiar milestones have native proof kinds: authenticated native setup,
complete native inventory, saved native publication policy, exact staged preview,
private article approval, public article observation and original native handoff.
The merge milestone is explicitly not required and has no proof. Public article
proof satisfies the native live and first-article-live observations; provider
acknowledgement or a draft cannot substitute for that public body proof.

Every proof binds the exact native scope, source where applicable, subject digest
and timestamp. A newer generation of the same original paid run invalidates its
dependent proofs; another run/envelope or generation rollback cannot replace it.
Public observations expire after 15 minutes, access/inventory after seven days.
Policy, preview, draft and consent references remain tied to current private
scope/source checks. Invalidated proof history is bounded to 32 records.

The reader reloads the current selected founder/company, private native policy
and active credential. It validates completed capture scope/inventory/receipt,
original paid source/outbox/refund state and the owning private review, stage,
approval and publication records. It only reads; it never captures, publishes,
fetches HTTP, charges, schedules or accepts incoming worker proof. Status or a
copied/rechecksummed receipt cannot replace the owning validator.

## Evidence and remaining implementation

The full 1,096-check no-database website group passes, including 18 new native
ledger/reader cases. They exercise the actual guarded synthetic native pipeline,
wrong owner/site/policy/source, another original payment, refunds, new generation,
false provider/live booleans, forged receipts, stale public proof, malformed
ledger types and bounded invalidation history. All model checks and migration
dry-run pass without changes; 779 production failure emissions are audited and
all 560 test modules are assigned.

The disposable-CI connection regression additionally reconstructs all native
milestones from real ORM source/capture/approval/publication records and checks
native completion without Git fields. Its database execution is remote-only
and pending CI.

These are ledger and proof-reader primitives, not an active native goal runner.
Native goal reservation/held first-article payment, dispatch/recovery, budgets
and strategy handoff, shared status/doctor and Chat setup/review UI still need
integration. Paid revision lineage, unpublish, hosted fallback and actual
WordPress/Ghost container/browser acceptance also remain. All rollout flags
stay off; no local database, paid model/generation, actual CMS write, wallet
service, merge or deployment ran.
