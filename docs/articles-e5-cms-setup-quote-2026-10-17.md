# Native setup quote before durable coordination

The current authenticated CMS owner can read the actual first-article price and existing publication choice before a native goal exists. The quote binds the selected company, current connection generation, configuration revision and platform. When a private policy already exists, it includes its actual review/auto mode and bounded author/category labels. A missing policy is represented as absent; the read does not guess an author or category, contact a provider, create consent, reserve a goal or spend points.

The price comes from the same canonical price helper used by the original native billing reservation. A legitimate zero is retained; missing, malformed or concurrently changed prices do not become zero. Setup remains free. The quote is omitted after any existing goal, including a terminal goal, so it cannot invite an unreviewed second debit or successor article.

Authority, policy and price are rechecked after the read. A changed owner, company, credential/policy binding or configuration cannot return the old quote. If a goal commits while the quote is being read, shared status selects the actual operation rather than offering another setup action. The optional nativeSetup field sits behind the existing disabled native status/goal rollouts; the Git setup plan remains separate.

The quote digest identifies displayed public choices. It is not a signature or authorization. The next implementation must persist the owner's accepted price, review/defaults choices and original scope in a scheduled cms-setup operation before provider discovery. Private typed leases must fence the policy read/commit and eventual original goal/hold reservation. Lost responses must reuse that same intent. A browser-only configure-then-start sequence would stop when the page closes and is not a one-shot implementation. A real setup status mode can show that scheduled preparatory operation without inventing a policy ID, native goal or milestone proof.

Validation: 1,246 database-free website tests pass, including 11 new quote cases; 32 focused quote/status/start cases pass. Coverage includes zero/unknown/changing price, current mode/policy/revision, missing policy, terminal and concurrent goals, stale owners, private-field exclusion, unchanged operations and no HTTP/debit on the read. B1 audit covers 810 emissions; test assignment covers 572 modules; model dry-run has no changes. Database/provider integration remains remote-only.

This is the quote read foundation, not the durable coordinator or an enabled setup UI. Native connection/reconnection, setup coordination/controls, completed-public-proof maintenance, revisions/unpublish, hosted fallback and actual CMS/browser/zoo acceptance remain outstanding. All flags stay off; no customer, provider, wallet, model, merge or deployment operation was performed.
